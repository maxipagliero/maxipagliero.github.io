Anti-Cheat Behaviour Detection

A full ML pipeline that flags cheating players from match telemetry: 10k match events across 800 players, about 5% of them cheaters.

  • SQL player aggregates and feature build, then feature engineering in notebooks
  • Trained and compared Logistic Regression (baseline), Random Forest and XGBoost
  • XGBoost scored the highest ROC-AUC and F1 on the held-out test set
  • Evaluated with ROC and precision-recall curves, confusion matrices and feature importances
  • Production strategy report for rolling the detection out
